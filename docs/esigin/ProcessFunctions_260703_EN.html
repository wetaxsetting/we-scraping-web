Phase A

Configuration blocks — build the Workflow Template

Drag-and-drop Approval Line + Transaction Type to create a Template. New element: Setting time sets an SLA for each approval step.

ComponentContentNote
ApproverEmployee ID, Name, Position…Approver source
Setting timeLimited 60/90 min… or UnlimitedPer-step SLA → reminders / escalation

Transaction TypeWeCMS (Internal Transfer, Vendor/Expense/Oversea Payment, Payroll) · Misa AMIS · OthersDetermines the execution lane

Key point

Differences across the 3 lanes

Only Misa AMIS goes through a mandatory digital-signing step; WeCMS/Others stop at internal approval. Others adds a disposal lifecycle (DISPOSED) and reuse (Copy).

CriterionWeCMSMisa AMISOthers
NaturePayment/transaction requestAccounting documentOther documents
EndingAPPROVEDFinal digital sign (Approval Ln) → SIGNEDAPPROVED
SpecificsMulti-level internal approvalApprove 1..n‑1 then mandatory digital sign USB/Smart CA/HSMAllow Copy request
Distinct state—IN PROGRESS · SIGNEDDISPOSED (disposal due, with approval)
RejectREJECTED → redoREJECTED → redoREJECTED → redo
Misa AMIS signing flow: document created in Misa → export/download PDF → upload into the internal e-Sign → approve/sign → final step: signature + seal via USB Token → previewing again shows the digital signature info right at the signing position on the document.

Function catalog

6 configuration · 10 execution

A Configuration (Template)

  • A1 Manage Approver (ID/Name/Position)
  • A2 Setting time — per-step SLA (limited/unlimited)
  • A3 Configure Approval Line (nested multi-level)
  • A4 Select Signing method (internal / digital sign)
  • A5 Select Transaction Type (WeCMS/Misa/Others)
  • A6 Create Workflow Template (drag-drop)

B Execution (Request)

  • B1 Create Request Approval — Others: Copy
  • B2 Request Approval (submit)
  • B3 Approval Box (approval inbox)
  • B4 View Detail — Update contents + Attach file
  • B5 Approval 1..n (multi-level)
  • B6 Signing (Misa AMIS) — digital sign USB/Smart CA/HSM → SIGNED
  • B7 Reject (with reason) → REJECTED
  • B8 Dispose (Others) — DISPOSED with approval
  • B9 State & history management
  • B10 SLA & reminders/escalation per Setting time
Compliance add-on: insert into B6 Signing a chain of certificate check (OCSP/CRL) → timestamp (TSA) → PAdES/XAdES sealing; attach a retention class on storage to meet 5/10-year/permanent periods.

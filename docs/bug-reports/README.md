# Bug Reports (shared)

Bug tracking is **global for both systems** (JEX + Refactor) and is maintained in the
shared workspace bug-tracker, **outside this repository**. Tag each report with
`System: JEX` or `System: Refactor`.

> The shared bug-report tree is not part of the `wecms-web` clone. Frontend (Refactor)
> bugs are tagged `System: Refactor`. If you need a local home for frontend-only bug
> notes before they reach the shared tracker, add them under this folder.

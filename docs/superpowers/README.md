# superpowers/

Reusable frontend "superpowers" — shared cross-cutting capabilities and patterns
that any page can adopt (e.g. Excel export, View Setting column persistence,
saved-ID/auth helpers, common dialog/table patterns).

Add one file per capability as it is extracted and generalized from a feature.
Until a capability is documented here, its design lives with its originating
feature under [../features/](../features/) (cross-cutting architecture: [../architecture/](../architecture/)).
